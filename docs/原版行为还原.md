# 原版行为与动画还原 · 2026-10-25

本轮响应怪物 AI、碰撞和剧情动画的逐项还原要求。原有地图、计分、菜单和存档保留；没有把 Flash 类直接翻译成 JavaScript，也没有引入 Flash 播放器。

## 核对与实现

依据为已留存的韩版 `digboy_save_v1.swf` 与中文 `ogoon_*.swf`。核对对象为 `NPC`、`BigDragon`、`Character`、`Player`、`Boss`、`SubBoss`、`BossArm`、`Explode`、`TileView`、`GameStatus`、`EventManager` 和剧情阶段配置。每个运行资产仍是独立图片、视频或数据，原脚本不在浏览器中执行。

| 项目 | 已实现的原版行为 |
| --- | --- |
| 普通怪 | 速度 2；落差／墙体探测与连续反向计数；腾空时仍横移；删除自创的固定半径巡逻 |
| 大型怪与守门怪 | 速度 2、挖掘力 3、顶部探测、每秒随机转向；腾空停止横移；与玩家共享地块裂纹进度 |
| 激活区域 | 按镜头可见的纵向 480px 区间更新，包括横向画外怪物 |
| 首领公共行为 | 速度 3；50px 追击容差；玩家高出 100px 时起跳，初速 −21，空中横移 9；原版落地震动；101 个逻辑帧启动攻击 |
| 最终首领 | 普通攻击动作第 11 帧发射飞拳；低于 70% 且场上召唤怪少于 3 时使用召唤动作，每 4 个逻辑帧生成一只，最多 8 只；低于 40% 显示原版怒气 |
| 守关首领 | 第 600 帧开始召唤、随后每 200 帧检查、上限 7；低于 40% 使用长挥臂，不混用最终首领的集中召唤 |
| 飞拳 | 独立 30fps 时钟；速度 3–4、每帧转向 1–4 度、前 29 帧追踪、寿命 200–249 帧；朝左的翻转与旋转同时应用到绘制和碰撞；受击保护期间接触不提前消失 |
| 首领血条 | 替换通用矩形，使用原版 BossHP 的头像和 50 档血量素材，原位置 (40,410) |
| 地形碰撞 | 42px 瓦片；人物左右探测偏移 −16/+15、上下 −29/−1；首领地形宽度用 −71/+70；逐步移动防止穿墙；顶到天花板后正确下落 |
| 受击碰撞 | 玩家原始受击框为 x=−12..10、y=−26.5..−4.5；普通怪使用动画整体边界，首领使用根部与动作内的 coll_mc；不再按圆形距离命中 |
| 受击反馈 | 接触基础伤害 30，再减装备防御；500ms 输入锁、约 2550ms 受击保护；删除无来源的横向瞬移；首领采用原版明暗闪烁 |
| 炸弹与爆炸 | 原位置偏移、超级炸弹 1.2 倍爆炸；逐帧爆炸边界与目标 coll_mc 检查；一次爆炸只命中一个目标，允许命中飞拳；爆炸开始后允许继续放下一颗 |
| 挖掘 | 七段破土；原硬度／钻头计数，裂纹中断后保留，存档恢复；向下挖掘优先于横移，冰面加速不作用于喷气 |
| 死亡和掉落 | 怪物死亡动作后出现奖励盒，接触拾取时才加金币；首领死亡后保留 5 秒退场；人物先播放 2 秒死亡，再结算或复活动作 |
| 镜头 | 逻辑时钟更新的原版横向死区和纵向跟随，移除刷新率相关插值 |

攻击状态的动画时间与碰撞框时间共用，停止型动作播放到末帧停住。原版的失控飞拳角度返回值、不可见受伤玩家等缺陷不作为必须复制的目标。

## 完整剧情

13 段 640×480、30fps 中文动画全部使用原时间轴导出，包含原中文画面及原音；原有 stop() 的子动画保持停止姿态。音频按原触发帧混合，保留循环、起止点与左右声道音量包络。`loading3` 原资源无声音，不添加配音。

| 触发 | 顺序 |
| --- | --- |
| 三项训练完成／跳过训练 | opening → quest1 |
| 守关首领退场 | quest2 → loading1 → loading3 → quest3 |
| 第二矿区取得特殊矿 | quest4 → loading2 → quest7 |
| 第二矿区首次达到 200m | quest5 |
| 救出矿工 | quest6 |
| 最终首领退场 | ending_happy 或 ending_not |

支持暂停、逐段跳过、后台暂停、刷新后续播、结局重看。原关卡开始前不再放错剧情，回访矿区／结局后继续探索不重复章节。影片缺失会显示中文重试提示，不静默退回单张截图。资源有中韩英日分支入口，当前实际提供中文版本。

视频清单、帧数、时长、音轨及源文件／交付文件 SHA-256 见 `evidence/native-movie-validation.json`。全部 13 段经 ffprobe 核对；开场为 1476 帧／49.2 秒，两个结局为 358 帧／11.933 秒和 960 帧／32 秒。

## 保留的体验修复

可靠钥匙、满包不吞矿物／掉落、掉落不短时消失、首领房重试不重复收费、氧气站补充基础炸弹、防后台耗氧、暂停和备份存档仍有效。玩家受伤半透明可见。死亡救援保留装备及特殊矿物。

## 验证证据

- `npm run check`：全部运行模块及服务器语法检查通过。
- `npm test`：32 项通过，日志 `evidence/native-tests.txt`。新增原始帧边界、攻击节拍、两类召唤阈值与数量、飞拳追踪和寿命、死亡／复活、碰撞探测、挖掘中断续存、剧情顺序和非法续播存档检查。
- 有限补给最终首领测试使用实际移动方向和道具入口，含急救与氧气补给，没有无敌和直接扣首领血，推进至圆满结局。该自动模拟不冒充浏览器人工通关。
- 浏览器通过正式文件导入进入隔离 `?profile=qa`：完整开场自然衔接进入矿区；18.57 秒处暂停，刷新后“继续冒险”恢复到约 18.75 秒；结局播放、暂停、跳过、重看和返回探索入口均实际操作。
- 浏览器实际方向键移动、投放超级炸弹、喷气触发首领追击／跳跃、受击与暂停；截图 `evidence/native-boss-combat-qa.png`。结局截图 `evidence/native-ending-movie-qa.png`。这些使用构造 QA 存档，不是自然到达首领的证据。
- 视频 HTTP 返回 `Content-Type: video/mp4`；Range 0–1023 返回 206、准确 Content-Range 和 1024 长度。
- 用户原存档在独立根路径保存后更新页面；QA 不覆盖该存档。浏览器检查未观察到控制台错误。

本轮不把源规则核对和局部浏览器检查扩大为全游戏逐帧等价认证；完整同输入 Flash/HTML5 双录像、全程人工通关与手机实机仍未进行。

## 重建入口

- `scripts/exportActorGeometry.java`：提取原动作中的动态矩形、停止帧与变换到 `src/actor-geometry.js`。
- `scripts/assetsRender.java` + `scripts/build_native_actors.py`：完整玩家／怪物／首领动作；碰撞占位不绘制，怒气单独渲染。
- `scripts/pack_boss_hp.py`：整理 sprite 204 的 50 档原血条。
- `scripts/renderMovie.java` + `scripts/build_movies.py`：逐帧离线渲染、原音混合，导出 HTML5 MP4；`--reuse-video` 只重建音轨，避免重复大导出。
