# 挖地小子 · 原生浏览器版

本地可玩的中文 HTML5 重制。使用原作提取的地图、精灵、图集、音效与物品数据，以独立编写的 JavaScript 模拟和 Canvas 2D 渲染运行。游戏不加载 SWF，也不依赖 Flash、Ruffle、插件或在线服务。

## 启动

需要 Node.js 22 或更新版本，无 npm 依赖需要安装。

```sh
npm start
```

打开 <http://127.0.0.1:8146/>。服务仅监听本机。使用 `PORT=其他端口 npm start` 可以指定端口。

## 游玩

- `← →` 移动／横向挖掘，`↓` 向下挖掘，持续按 `↑` 喷气返回地面。不能向上挖土。
- `A S D F G` 使用快捷栏道具；初始分别对应急救箱、小氧气胶囊、普通炸弹、超级炸弹、超威力炸弹。
- `E` 与商店、博士、Boss 门、传送门交互；也可以点击画面中的建筑。
- 右侧仪表内点击小地图可展开全图；点击右边缘齿轮打开背包；悬停能量或氧气表可查看中文数值。
- `B` 背包，`M` 地图，`Esc` 暂停。触控设备显示方向键和炸弹键。
- 普通炸弹对付敌人，超威力炸弹破脚下岩石；自己的炸弹不伤害自己。
- 购买装备会自动穿戴。地图展示已探索区域及关键地点。三个矿区解锁后可从地面商店返回探索。

完整流程包括三项训练、三个原始矿区、救援任务、守关 Boss、最终 Boss、三种特殊矿物与两种结局。

## 存档

浏览器本地自动保存、手动保存、上一份备份恢复、JSON 导入／导出。没有登录或网络存档依赖。自动保存约每 30 秒触发，交易及关键进度也会保存；后台、暂停和页面关闭前保存。

不同浏览器和端口各有独立存档。转移时使用设置内的导出／导入功能。浏览器清理站点数据会清掉本地存档，因此重要进度建议导出。

## 架构

- `src/core.js`：与 DOM、渲染、声音解耦的游戏模拟与存档验证；按原代码的 27ms 固定步长更新。
- `src/renderer.js`：原版 42px 瓦片、可见区域裁切、动画、粒子和地图；精灵时钟 30fps。升级头盔帧按需加载。
- `src/hud.js`：原版机械仪表素材、实时滚动小地图、深度字模和 101 档氧气表盘；使用统一的 640×480 坐标。
- `src/ui.js`：中文菜单、背包、商店、存档、暂停和键盘焦点管理。
- `src/audio.js`：原版背景音乐与音效，用户首次交互后激活。
- `src/i18n.js`：`zh-CN / ko / en / ja` 语言入口与中文回退；中文内容完整，其他语言仅基础接口与少量键，未宣称已完成翻译。
- `public/data/original.json`：7 张原始地图、38 项物品、真实阶段推进、规则参数与来源记录。物品 ID 和存档不依赖显示语言。
- `public/assets/manifest.json`：原作资源、动作状态、帧率、锚点和路径；人物外观与规则分离。
- `tools/server.mjs`：本地静态服务器。

没有复制 ActionScript 类或执行反编译代码。地图、物品配置和素材是从原版提取的数据；行为根据调研记录重新实现。

## 验证

```sh
npm run check
npm test
```

浏览器 QA 存档可用 `node tools/qa-saves.mjs` 生成，通过设置中的正式导入入口载入。在 `?profile=qa` 下操作会使用独立存档空间。

详见 [验收记录](docs/验收记录.md)。

## 当前还原边界

这是完整流程可玩的第一版，不是已经通过逐帧对照验收的原作等价物。

- 保留原地图与主要数值、27ms 逻辑时基、矿区推进、氧气和装备规则。
- 过场使用原版中文关键帧加独立对白流程，尚未播放完整原版动画。
- 玩家、怪物动作使用抽取的循环帧；头盔外观随升级变化，鞋和钻头的角色外观目前保持初始档。
- 碰撞用明确几何边界替代 Flash 动态 `hitTest`，怪物 AI 和 Boss 攻击以新状态逻辑实现；不能声称每个时序、半径、动画与原版完全相同。
- 主流程关键节点与有限补给 Boss 战通过自动检查，浏览器验证了多个真实操作；没有完成从新游戏开始全程人工通关，也没有手机实机验收。
